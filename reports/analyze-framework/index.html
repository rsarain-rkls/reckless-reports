01 Qué es esto

Un sistema de análisis y ejecución que funciona para dos mundos: ingeniería de software (requerimientos, épicas, sprints técnicos) y creación de contenido (guiones, carruseles, campañas, lanzamientos). El mismo proceso. Diferente output.


La premisa central: todo input —un transcript, una idea, un requerimiento, un dictado— contiene dentro de sí la estructura de su propio output. El trabajo es extraerla, no inventarla.

02 Los 5 Lentes de Análisis

No son pasos secuenciales. Son filtros que se aplican simultáneamente sobre cualquier input. Cada uno hace una pregunta distinta al mismo material.

L1
Simple Stick
Ken Segall — Insanely Simple
Simplicidad como religión. Después de cualquier análisis, el material debe poder reducirse a una sola idea, una sola caja. Lo que sobra, sobra.
"¿Se puede decir con menos?"
L2
Modos de Ver
John Berger — Ways of Seeing
Ver no es pasivo — es un acto político. Para contenido visual: el texto no describe la imagen, la imagen recontextualiza el texto. El contexto es el diseño.
"¿Qué comunica realmente, más allá de lo que dice?"
L3
Free Play
Stephen Nachmanovitch — Free Play
El impulso inicial es señal, no ruido. Antes de estructurar, buscar qué surge orgánicamente. La improvisación disciplinada es la forma más alta de creatividad.
"¿Dónde está el impulso genuino en este material?"
L4
Jobs To Be Done
Christensen / Ulwick
La audiencia no consume contenido — contrata contenido para que haga un trabajo. Funcional (aprender cómo), emocional (sentirse capaz), social (parecer informado a sus pares).
"¿Para qué trabajo contratan esto?"
L5
Working Backwards — PR/FAQ
Amazon — Colin Bryar & Bill Carr
Empezar desde el resultado final. Escribir el comunicado de prensa antes de producir nada. Fuerza claridad sobre: quién es la audiencia, cuál es la promesa única, qué objeciones van a surgir. Si no podés escribir el comunicado, no entendés todavía qué estás haciendo.
"Si esto funcionó perfectamente, ¿cómo dice el comunicado?"
03 Los 3 Modos
Modo Contenido
Input: idea, dictado, brief, transcript de llamada con cliente → Output: formato definido, hook, estructura de piezas, cadencia, sprint de producción. Para carruseles, guiones, campañas, lanzamientos.
Modo Software
Input: requerimiento, tarea técnica, problema de sistema → Output: épicas, historias de usuario con criterios de aceptación BDD, sprint plan técnico, documentación en repo. Para sistemas, apps, automatizaciones.
Modo Lanzamiento
Input: nuevo producto, servicio, cliente, campaña → Output: PR/FAQ completo, mapa de contenido pre-lanzamiento, estructura de Notion, hoja de ruta 30 días. Para cualquier cosa nueva que necesita una estrategia de salida al mercado.
04 El Proceso — 3 Sprints

Cada análisis corre en tres sprints consecutivos. Total: 60–90 minutos de trabajo activo. El output es un brief ejecutable.

Sprint 1 — 20 min
Extracción Temática
  • Leer/escuchar el input sin intervenir
  • Identificar 3–5 temas core inductivamente
  • Extraer citas textuales representativas
  • Aplicar L3 — ¿qué surge orgánicamente?
  • Mapear tensiones y contradicciones
Sprint 2 — 25 min
Estructura & Estrategia
  • JTBD: definir el trabajo real de cada pieza
  • Simple Stick: una idea, una caja
  • PR/FAQ inverso: escribir el comunicado final
  • Definir formato y criterios de aceptación
  • Sprint plan: fechas, piezas, responsables
Sprint 3 — 25 min
Documentación & Notion
  • Armar estructura PARA en Notion
  • Crear página del proyecto con brief
  • Generar este reporte HTML
  • Guardar en repo Git
  • Link compartible listo

06 Cómo invocar el sistema
Comando
Modo libre — cualquier input
Simplemente describí lo que tenés, querés hacer, o lo que te está frenando. Sin estructura necesaria.

Ejemplos válidos:
— "Quiero hacer un carrusel sobre digestión para Farmacia 26, mujeres 30-45, tono educativo"
— "Acá está el transcript de la llamada con el cliente nuevo, ayudame a sacar qué necesitan"
— "Necesito armar el sistema de automatización para Napoli, no sé por dónde empezar"
— "Tengo que presentar el proyecto de la facu en agosto, ayudame a dividirlo en sprints"
Output
Qué vas a recibir
Un reporte HTML como este, con:

→ Temas core extraídos del input
→ JTBD statements por pieza
→ Filtro Simple Stick — la idea madre
→ PR/FAQ — resultado esperado + objeciones
→ Sprint plan con días y tareas
→ Estructura lista para Notion
→ Archivo guardado en el repo + link compartible
Simple Stick — La idea madre del sistema
Todo input tiene una estructura interna.

Si el análisis produce más de una idea central, no terminó. Seguir reduciendo hasta que quede una sola que contenga a todas las demás.
